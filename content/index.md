# Systems Thinking — Study Notes

This is a systematic review of the "Systems Thinking" material in this folder, organized as a
foundation for a later conceptual framework of "situations" (grounded in image schemas from
Cognitive Linguistics). **This phase is a faithful review of systems-thinking content only** —
no cognitive-linguistics framing has been added yet. That mapping is a deliberate follow-up
phase once this base is solid.

## Sources

Two documents anchor this documentation:

- **`ebook_Systems Thinking.pdf`** — *Systems + Thinking: An Overview* (Joss Colchester, 2016).
  A 42-page, textbook-style introduction that progressively builds a formal vocabulary: from the
  analysis/synthesis distinction, through the anatomy of a system (elements, functions,
  boundaries, environment), to relations, emergence, hierarchy, dynamics, and homeostasis.
  This is the primary source for definitions and structure.
- **`Slide_Systems_Thinking_Guide.pdf`** — *Systems Thinking: A Short Guide* (Systems Innovation
  Network, CC-licensed). A 23-slide didactic summary, pitched at facilitators, that frames
  Systems Thinking as a *paradigm shift* along four axes and introduces "Systems Awareness"
  (how our worldview shapes what we see, do, and create). Used here mainly for the framing in
  [`01-worldview-and-paradigm.md`](01-worldview-and-paradigm.md).

Both are part of a **20-guide "Systems Innovation" publication series**
(systemsinnovation.network). The slide deck's map of the full series is reproduced below for
context — it shows where "Systems Thinking" sits relative to adjacent topics:

> Systems Thinking, Systems Awareness, Systems Theory, Complexity Theory, Adaptive Systems,
> System Inquiry, Systems Modeling, Mapping, Actor Mapping, Leverage Points, Systems Change,
> Horizons, Feedback Loops, Multi-Level, Narratives, Systems Building, Networks, Value Network,
> Scaling Change, Systemic Evaluation.

The folder also contains PDFs (ebook and/or slides) for several of these other guides —
**Complex Adaptive Systems, Complexity Theory, Emergence Theory, Network Theory, Systems
Modeling, Systems Awareness, System Theory**. These were all read in full and cross-checked
against the base documentation; each was found to be substantially redundant with it (same
series, heavy shared framing), but each also contained a handful of genuinely new, non-redundant
ideas. Those have been folded in — either as short additions to chapters 1–8, or as three new,
deliberately short chapters (9–11) where the new material formed its own coherent topic. The
*rest* of each guide (technical/methodological detail, worked applications, facilitation
material) remains out of scope — see [`02-system-fundamentals.md`](02-system-fundamentals.md)
onward for where each addition landed.

## Note on sourcing

Each chapter cites which source (ebook chapter / slide number) its content comes from, and
preserves notable quotes from the original authors (Ackoff, Meadows, Senge, Von Bertalanffy,
Cabrera, etc.) attributed as in the source material. Where the two sources differ slightly in
emphasis or terminology, this is noted rather than silently reconciled.
