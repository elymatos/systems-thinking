# Systems Thinking — Study Notes

A systematic review of Systems Thinking source material (ebooks + slide guides from the
Systems Innovation Network's 20-guide series), organized as a foundation for a later conceptual
framework of "situations" grounded in image schemas from Cognitive Linguistics.

Published at: **https://elymatos.github.io/systems-thinking/**

Content lives in [`content/`](content/) as plain Markdown and is built with
[Quartz](https://quartz.jzhao.xyz/), deployed automatically to GitHub Pages on every push to
`main` (see [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)).

## Local development

```bash
npm install
npx quartz build --serve
```
